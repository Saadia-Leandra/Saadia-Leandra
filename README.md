## 🚀 Projets

### 🎓 StageTec – Plateforme de gestion automatisée des stages
Application qui centralise tout le processus de stage : demandes, corrections, contrats, signatures électroniques et notifications. Projet d'équipe (4 personnes, 3 sprints agiles, juin–août 2026) à l'Institut TECCART.

- Frontend React/Vite avec interfaces adaptées à chaque rôle (étudiant, superviseur, conseillère, comptabilité, direction)
- Module de kilométrage : calcul automatique de la distance, de la durée et du remboursement
- Module de paie des superviseurs : calcul côté serveur et export CSV
- Authentification JWT, accès contrôlé par rôle, CRUD des utilisateurs
- Suite de 51 tests automatisés
- **Technologies :** React, Vite, Node.js, Express, MySQL, JWT
- **Dépôt :** [Saadia-Leandra/Projet_stage](https://github.com/Saadia-Leandra/Projet_stage)

### 📚 Digilib – Système de gestion de bibliothèque
API REST asynchrone et interface React pour gérer les livres et les emprunts.

- Authentification JWT, hachage bcrypt, rôles Admin/Membre
- Règles de gestion automatisées : maximum 3 emprunts simultanés, vérification des stocks, blocage de la suppression d'un livre emprunté
- Frontend avec React Router v6, contexte d'authentification global et parcours protégés selon le rôle
- **Technologies :** FastAPI, MongoDB, React
